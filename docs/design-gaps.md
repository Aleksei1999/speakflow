# Чего не хватает в дизайне (Figma) — RAW English

Составлено 10.09.2026 по итогам проверки бэкенда и кабинетов. Всё ниже нужно продукту, но макета нет: в коде либо ничего не сделано, либо стоит заглушка вне дизайна.

## Админ

- **Входящие заявки преподавателей.** Список заявок, раскрытие с почтой, контактом (telegram / телефон) и полем «о себе», кнопки «Одобрить» и «Отклонить». Заявки уже копятся в базе, открыть их негде.
- **История заявок учеников.** Сейчас показываются только новые заявки с пройденным тестом. Нужны: заявки без теста, обработанные и отклонённые.
- **Кнопка «Выйти».**
- **Настройки админа.** Смена пароля, фото, имя.

## Учитель

- **Кнопка «Выйти».**
- **Настройки.** Смена пароля, фото, описание. Ссылка из старого меню ведёт на несуществующую страницу.
- **Создание группы.** API есть, экрана нет: сейчас группы создаёт только админ.
- **Отмена урока.** Экран подтверждения отмены урока из расписания (перенос есть, отмены нет).

## Ученик

- **Кнопка «Выйти».**
- **Настройки.** Смена пароля, фото, уведомления, подключение Google Calendar. Есть только старая страница вне нового дизайна.
- **Отмена записи на лекцию.** После записи кнопка просто гаснет «Вы записаны», отменить нельзя.
- **Отмена урока учеником.** API есть, кнопки в расписании нет.

## Регистрация и вход

- **Вкладка «Учитель» на регистрации как заявка.** Форма: имя, фамилия, почта, telegram или телефон, согласие, кнопка «Отправить заявку». Экран «Заявка отправлена». Пока вкладка ведёт на страницу /teach.
- **Экран «Проверьте почту»** после регистрации.
- **Состояние «ссылка устарела»** при переходе по старой ссылке из письма.
- **Ошибки входа:** почта не подтверждена, аккаунт отключён, слишком много попыток.
- **«Забыл пароль» и «Новый пароль».** Сейчас страницы в старом стиле.

## Общее

- **Уведомления на платформе.** Колокольчик и список событий (отложено, но экрана нет).
- **Письмо преподавателю с доступом** после одобрения заявки: сейчас шаблон из кода.
